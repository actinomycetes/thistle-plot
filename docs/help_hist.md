All releases are beta (0.x). Earlier builds were called PyPrism / PyPrism Pro; numbers before 0.6.0 are mapped from the old v1–v5 builds.

| Version | Name | Changes |
| --- | --- | --- |
| 0.9.0 (6 Nov 2026) | Thistle Plot | Figures can be adjusted in place: with a figure open, the Plot button becomes **↻ Update plot** and redraws that tab instead of adding a new one (also ↻ Update in the figure's top bar); **+ New** beside the button and **+** at the end of the plot tabs open a new figure; optional **Live update** redraws the open figure as you change plot options (paused for heatmaps, PCA and volcano plots on tables over 2,000 rows); updating a linked figure keeps the test's stars only while the data are unchanged, otherwise it is unlinked with a note |
| 0.8.2 (5 Nov 2026) | Thistle Plot | Significance stars, brackets and gene lists now belong only to the figure created by a specific run of a test: re-plotting the same settings by hand, or after closing the tabs, no longer carries them over (🔗 still re-creates the linked figure with them); PCA now lists every component (variance, scores for all PCs, top loadings for any PC with a selector, loadings CSV for the first 10 PCs) and the PCA plot lets you choose the X and Y components before plotting as well as afterwards |
| 0.8.1 (5 Nov 2026) | Thistle Plot | Clearer result tab names (e.g. "Unpaired t-test (Welch)" instead of "t-ind"); ⬇ Tables (CSV) on every result, and full gene tables for Rank Product, Volcano and PCA loadings; Rank Product rewritten to rank up and down separately (each with its own FDR), effect defined as Group B vs Group A with a difference / log2-ratio choice (previously always a ratio, even on log data); Rank Product and large per-row t-tests open a linked heatmap of significant up and down genes across replicates; heatmap can show replicate columns and a linked gene list; new 300-gene screen example for Rank Product |
| 0.8.0 (5 Nov 2026) | Thistle Plot | Dunnett's test for one-way ANOVA vs a control (exact multivariate t; checked against simulation and SciPy); one-way ANOVA can compare against several ticked control groups; two-way ANOVA post-hoc tests (simple effects, all cells, main effects) with brackets on the bar chart, factor labels from group names, and a check for unbalanced designs (cell-means table fixed); Kaplan–Meier with any number of groups (Prism layout), log-rank test, hazard ratio and corrected pairwise log-rank; Kolmogorov–Smirnov test (two-sample exact, or Lilliefors normality) with a new Cumulative Distribution (ECDF) plot; large datasets: data table draws only visible rows, paste grows the table and can fill row names, PCA rewritten to work on samples with tens of thousands of genes (and lists top loadings), heatmap limited to the most variable rows, long result tables show the top 200 rows with a full CSV download; Rank Product p-values now use the exact distribution of the product of rank fractions |
| 0.7.0 (5 Nov 2026) | Thistle Plot | Holm–Šídák correction added everywhere multiple comparisons are corrected, with a correction choice for t-tests vs control, Kruskal–Wallis (Dunn's), non-parametric multi-pair modes, correlations and Multiple Testing; ANOVA Tukey HSD is now exact (studentised range) and "vs control" corrects only those comparisons; descriptions of every test and option, with "Choosing between similar tests" and "Corrections" tables in Help; each result lists the options and data used; 🔗 re-creates a closed plot or result; 📋 Example moved beside the Visualisation and Statistical Test menus and loads data suited to the choice (13 datasets); Clear and new datasets reset to an empty 2-group table; Kaplan–Meier estimate corrected for censoring, plotted on a time axis with censor ticks; dose–response fitted and plotted on a log concentration axis; Multiple Testing plot shows the chosen correction and p = 0.05 line; 5PL regression model fixed; Fisher's exact reads groups as columns |
| 0.6.2 (5 Nov 2026) | Thistle Plot | Per-row t-tests (unpaired and paired) now auto-plot a linked Bar + SD + Dots By sample figure with per-sample significance brackets; Mann-Whitney, Wilcoxon and Rank Sum "vs Control" mode now compares the control with every other group (previously ran a single pair); FDR (BH) for all-pairs non-parametric tests now uses the standard step-up adjustment; Multiple Testing, Kaplan-Meier and Volcano now auto-plot a linked figure; Heatmap no longer opens two plots; Pearson/Spearman options panel fixed for 3+ groups; By sample bar charts no longer clip SD bars or dots at the top; round-number y-axis ticks in App style too |
| 0.6.1 (5 Nov 2026) | Thistle Plot | Export fixes: App-style PNG/SVG/PDF no longer come out blank (transparent background) and are now saved at 2× resolution; Publication style now applied to the "By sample" bar and box plots (thick L-shaped axes with tick marks, larger bold labels, gap before the first bar, legend spacing), to dots-only plots (dots spread instead of stacked) and to line plots (points no longer sit on the axes); round-number y-axis maximum when significance brackets are shown; box plot "Dots only" mode no longer draws whiskers; heatmap labels no longer overlap the colour key |
| 0.6.0 (5 Nov 2026) | Thistle Plot | Renamed from PyPrism Pro, with a new thistle icon; BETA and version badges in the header; built-in ❓ Help with these manuals; Publication (Prism-like) export style rebuilt so figures are redrawn at about 300 dpi instead of stretched (fixes distorted shapes, skewed fonts and coloured outlines); Prism-like axes, greyscale fills, round-number ticks and non-overlapping dots; marker shapes per series on line and scatter plots; project files now `.thistle` (`.pprism` still loads) |
| 0.5 | PyPrism Pro v5 | Datasets renamed by double-click; Visualisation and Statistical Test sections visually separated |
| 0.4 | PyPrism Pro v4 | Rebuilt after file damage; PCA "All replicates" mode fixed; Bar/Boxplot "Group mean" shows one dot per sample row |
| 0.3 | PyPrism Pro v3 / v3b | First single-file web app in pure JavaScript, replacing Python |
| 0.1–0.2 | PyPrism v1–v2 | Python desktop and Streamlit prototypes |
